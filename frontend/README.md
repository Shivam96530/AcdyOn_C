# AcdyOn Premium Homepage Redesign

A premium, cinematic, interactive homepage for AcdyOn Global Executive Education & Academic Recognition Platform.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 📁 Project Structure

```text
src/
├── components/     # React components
├── data/          # Static data (locations, programs, universities)
├── App.jsx        # Main application
├── main.jsx       # Entry point
└── index.css      # Global styles
```

## 🎯 Key Features

- **Cinematic Intro**: Motorcycle journey animation with skip option
- **Find Your Path**: Interactive pathway discovery
- **Global Map**: Interactive world map with location markers
- **Responsive**: Works on 390px - 1440px+
- **Accessibility**: Reduced motion support, keyboard navigation
- **Performance**: Optimized animations, lazy loading

## 🛠 Tech Stack

- React 18 + Vite
- Tailwind CSS
- Framer Motion
- React Leaflet (OpenStreetMap)
- Lucide React Icons
